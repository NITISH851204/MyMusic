# MyMusic

Open-source, ad-free music player for Android that plays music from YouTube.
No ads, no tracking, no Google account needed.

> **Unofficial.** MyMusic is not affiliated with or endorsed by YouTube or Google.
> Using it may go against YouTube's Terms of Service. Use at your own risk.

## Features
- Search songs and videos, ad-free streaming
- Background play, lock-screen and notification controls
- Offline: download songs and play without internet
- SponsorBlock: skips sponsor, intro and outro segments
- Synced lyrics (tap the album art)
- Hindi / English home screen, recommendations, artists
- Likes, playlists, recent history, import YouTube playlists by link
- Local accounts (guest or username + password, stored only on your phone)
- Dynamic colors from album art, AMOLED black theme
- Share a YouTube link to "Play in MyMusic"
- Sleep timer, Volume Up double-press shortcut

## Download
Get the latest APK from the **Releases** page and install it.
Android 8.0+ is required.

## Build
The APK is built by GitHub Actions (see `.github/workflows/build.yml`).
Run the "Build APK" workflow to build and publish a release.
